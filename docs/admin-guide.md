# Инструкция: как управлять документами сайта

Сайт собирается статически через Astro и публикуется на GitHub Pages из ветки `main`.
Документы лежат в `src/data/*.json`, файлы в `public/<раздел>/`, панель управления в `/admin/`.

## Как открыть панель

1. Откройте `https://tochilkina-os.github.io/site/admin/`.
2. Войдите через GitHub.
3. Откройте раздел **Документы сайта**.

Важно: вход в Decap CMS требует настроенного OAuth посредника для GitHub. Без него панель
откроется, но авторизация не завершится.

## Что где лежит

| Раздел сайта | Данные | Файлы |
| --- | --- | --- |
| Образование | `src/data/diploms.json` | `public/diploms/` |
| Сертификаты | `src/data/certificates.json` | `public/sertificats/` |
| Самообразование | `src/data/self-education.json` | `public/self-education/` |
| Награды | `src/data/awards.json` | `public/awards/` |
| Родителям | `src/data/recommendations.json` | `public/recomendation/` |
| Мониторинг | `src/data/monitoring.json` | `public/monitoring/` |

## Как добавить документ

1. Выберите подраздел.
2. Нажмите **Добавить**.
3. Заполните поля:
   - **Название** — как карточка будет называться на сайте.
   - **Категория** — «Сертификат», «Грамота», «Рекомендации» и так далее.
   - **Файл** — загрузите PDF или DOCX.
   - **Иконка** — выберите из списка. Это имена иконок Phosphor, эмодзи больше не используются.
   - **Порядок** — 10, 20, 30. Чем меньше число, тем выше карточка.
   - **Показывать на сайте** — оставьте включённым.
4. Нажмите **Сохранить**. CMS сделает commit, GitHub Actions пересоберёт сайт за 1–2 минуты.

## Как скрыть документ

Выключите **Показывать на сайте** и сохраните. Карточка исчезнет, файл останется в репозитории.

## Мониторинг

В разделе **Мониторинг** один элемент — один учебный год. Заполняйте по порядку:

- **Учебный год** и **Группа** — подпись под диаграммой.
- **1 и 2 полугодие, %** — общие доли детей с показателями выше 75%.
- **Показатели развития** — ровно пять направлений, у каждого два процента.

Год, у которого **Порядок** больше, показывается на сайте первым при открытии.

## Правила приватности

- Не публикуйте документы с персональными данными детей.
- Перед загрузкой проверьте PDF и DOCX: ФИО детей, даты рождения, адреса и телефоны должны быть удалены.
- Для публичных материалов используйте PDF, DOCX оставьте для отчётов мониторинга.

## Локальная проверка

```bash
npm install
npm run dev      # http://localhost:4321/site
npm run build    # результат в dist/
```

Если сайт открыт двойным кликом по `dist/index.html`, стили и данные могут не загрузиться:
нужен локальный сервер или опубликованная версия.

## Если документ не появился

1. Подождите 1–3 минуты: GitHub Pages обновляется не сразу.
2. Обновите страницу с очисткой кеша: `Ctrl + F5`.
3. Проверьте поле **Показывать на сайте**.
4. Проверьте, что файл загрузился и поле **Файл** заполнено.
5. Откройте вкладку Actions в репозитории: сборка должна быть зелёной.
