# Сайт-портфолио Точилкиной О. С.

Портфолио воспитателя детского сада. Живой сайт: https://o-tochilkina.github.io/
(репозиторий `o-tochilkina/o-tochilkina.github.io`, Pages из ветки `main`, путь `/`).

В папке два слоя:

- **опубликованный** — статический `index.html`, `css/`, `js/` и файлы документов в корне;
  именно он отдаётся по адресу выше;
- **Astro-редизайн** — `src/`, `public/`, `dist/`; ещё не опубликован, собран под `base`.

## Запуск

```bash
npm install
npm run build    # сборка в dist/
npm run preview  # локальный просмотр сборки на http://127.0.0.1:4321/site/
npm run dev      # dev-сервер Astro, http://localhost:4321/site
```

## Структура

```
src/
  data/          JSON с документами, редактируется через /admin/
  components/    секции страницы и иконка
  layouts/       Base.astro: head, навигация, футер
  pages/         index, privacy, 404
  styles/        tokens.css, base.css, site.css
  scripts/       site.js: меню, reveal, переключатель лет, валидация формы
public/          только PDF и изображения, никаких DOCX — см. «Приватность»
sources-docx/    исходники DOCX (локально, в git не попадают)
tools/           локальный сервер для проверки сборки с base /site
```

## Приватность

Публикуются только PDF. DOCX в `public/` не кладём: внутри лежат служебные свойства
DOCX (автор, последний редактор, история правок) и весь текст сразу доступен для
скачивания. Схема простая:

1. исходник лежит в `sources-docx/<раздел>/` — папка в `.gitignore`;
2. правим и сохраняем как PDF в `public/<раздел>/`;
3. в `src/data/*.json` и в `index.html` ссылаемся на `.pdf`.

ФИО коллег перед публикацией сокращаются до инициалов, метаданные PDF чистим.

Оригиналы грамот воспитанников лежат в `public/achievements of pupils/`.
Для публикации используются их копии из `public/pupil-achievements/` без дополнительной
обработки. Перед добавлением новых документов необходимо проверить их содержимое.

## Дизайн-система

Значения зафиксированы в `src/styles/tokens.css` и повторяют правила скилла
`landing-page-design`:

- типографика по шкале Tailwind, один шрифт Manrope, без курсива и веса 900;
- отступы только из таблицы (2, 4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96);
- радиусы по шкале, вложенный радиус считается как `внешний − зазор`;
- фоны плоские, единственный градиент на заголовке hero;
- движение: `cubic-bezier(0.22, 1, 0.36, 1)`, анимируются только `transform` и `opacity`,
  учитывается `prefers-reduced-motion`.

## Документы

Данные лежат в `src/data/*.json`, файлы в `public/<раздел>/`. Правки через Decap CMS:
`/admin/`. Подробности в `docs/admin-guide.md`.

## Деплой

Опубликованная версия — статика в корне репозитория
`o-tochilkina/o-tochilkina.github.io`. GitHub Pages берёт её из ветки `main`, путь `/`,
сборка не нужна: `.nojekyll` отключает Jekyll, файлы отдаются как есть.

Astro-редизайн публикуется отдельно: `.github/workflows/deploy.yml` собирает его в `dist/`
и выкладывает артефактом. Для нового домена в `astro.config.mjs` нужен `base: '/'`.

## Проверка сборки локально

`npm run preview` поднимает `tools/preview_server.py`: он отдаёт `dist/` по пути `/site/`,
как на GitHub Pages. Отдельный скрипт нужен потому, что `astro preview` в этом окружении
слушает только IPv6 loopback.
